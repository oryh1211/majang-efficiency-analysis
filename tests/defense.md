# 舍牌时序与防守回归

网页在「舍牌时序与立直宣言」接收已核实的逐行事件。示例中的数字是该家牌河位置。带牌面的行用于已鸣走、不在牌河中的舍牌。

```text
下1 手切
上1 立直
下2 摸切
自 摸牌
```

同一座位的牌河从 1 开始录入。下一次摸牌、舍牌、鸣牌或拔北表示上一项已经过了荣和响应。在已核实牌谱中，若最后一行是舍牌且已确认通过，可另起一行写「通过」。原图的横放位置在置信度足够时被标为宣言牌，从单张图判断跨家先后则保留为未知。当前入口接受上述文本，不解析雀魂的原生牌谱链接。

```powershell
node tests/defense-regression.cjs
# 按 P0.md 准备截图测试素材后
node tests/defense-regression.cjs .vision-research
```

| 样本 | 校验 |
| --- | --- |
| 同牌种同枚数的顺序对照 | 调换下家一万、九万的舍牌顺序，安全牌和防守首推跟着对调。 |
| 两家先后立直 | 两次宣言之间打出的一万只对先立直者生效。最后一张响应尚未结束时不标安全。 |
| [三麻横放赤五筒](https://note.com/okuohouko/n/n13fe01366290) | 读出横放宣言位置，跨家顺序仍需牌谱。 |
| [四麻宣言牌被鸣走](https://note.com/aogumothumbing/n/n1ea612f3564e) | 对家已立直，原宣言位置未知。后续横放位置不作为原宣言。 |
| 用户提供的九索暗杠和发财碰 | 混合副露和多行牌河；无全桌时序，不生成跨家的「立直后已通过」。 |
