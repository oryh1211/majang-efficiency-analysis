# P0 实图回归

在 Windows PowerShell 与 Node.js 环境中运行以下命令。`MixedScreenshot` 指向用户上传的九索暗杠、发财碰原图。公开图的直链由 `p0-sources.json` 记录，测试素材放在忽略的本地目录。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/prepare-p0.ps1 -MixedScreenshot "C:/path/to/original.jpg"
node tests/p0-regression.cjs
```

| 样本 | 通过项与验证范围 |
| --- | --- |
| 用户原图 | 九索暗杠、发财碰以及独立摸到的南。自家牌河第三张读成五万并标黄。点图确认后保留其余识别结果，清除最后一个待确认项后出前三切。 |
| [四麻吃牌](https://note.com/quiet_myrtle257/n/n7d62c627a4a9) | 鸣牌响应帧拦截，吃后待切帧进入校对。评分浮层遮挡的副露标黄。 |
| [四麻白板碰](https://note.com/renrakuch/n/nf19e58609fdb) | 碰前与切牌后两个时点均拦截。该来源缺少刚碰完的待切图。 |
| [四麻两组副露](https://note.com/amutan_mj/n/n63b638604c11) | 八张手牌进入待切校对，右下角遮挡标黄。同局后续的对手回合被拦截。 |
| [三麻白板碰](https://note.com/okuohouko/n/n13fe01366290) | 同局鸣牌前、待切及后续牌局截图中，仅待切图生成三条建议并禁打白板。后续图验证横放赤五筒和自家两行七张牌河。后续图距该次切牌隔了一次行动。 |
| [四麻暗杠](https://note.com/shinux217/n/na14ba23a8b4b) · [三麻大明杠](https://note.com/okuohouko/n/nbd713ee7ea89) · [四麻加杠](https://note.com/shinux217/n/n42348a994488) | 验证四张牌组、加杠前后三张变四张、大明杠的横放赤五索，以及相应的非待切帧。暗杠与碰的混合验证来自用户原图。 |

待收集无遮挡四麻吃、四麻碰和三麻碰的同一动作连续三帧，以及已有三组副露时的同等真图。也缺大明杠或加杠与其他副露混合的完整真图。测试对部分可见牌保留点图确认，包括回放浮层遮挡、万子候选冲突、以及部分杠图的赤牌或牌河。
