# 本地校对学习 P0 验收

## 样本

- 学习集用会话附件中的东四局 14 张手牌原图，右侧牌河第六张原读三万，人工确认为二万。另取 [雀魂加杠牌局](https://note.com/shinux217/n/n42348a994488) 的 `sample-kakan-3` 自家第一行第四格作灰桌空位。现有识别已经跳过此空位，测试专门为这块真实截图构造一个校对位置，检验匹配器的空位判断。
- 独立整桌组使用 [带来源和人工标签的六图清单](vision-holdout.json)。同一篇牌谱的截图全部归入该组。学习集和独立组没有同图裁剪或同局相邻帧。五张有效待切截图合计 138 张牌，另有一张对手回合。
- 另用 [雀魂暗杠牌局](https://note.com/shinux217/n/na14ba23a8b4b) 的 `sample-kan-6` 对照灰桌和真的白板，核对 16 枚牌河读数及其中一张真实白板的输出。

## 复跑

在 PowerShell 运行。两个路径分别是会话中九索暗杠、发财碰的截图，以及东四局 14 张手牌截图。

```powershell
.\tests\prepare-p0.ps1 -MixedScreenshot '<混合副露截图路径>' -RiichiScreenshot '<东四局截图路径>' -IncludeVisionHoldout
node tests/local-learning.cjs .vision-research
node tests/vision-eval.cjs .vision-research
node tests/vision-eval.cjs .vision-research --local-learning
```

## 定点与边界回归

- 同一张已校对原图重传时，目标位由三万改为二万，该处黄标取消。移去样本后目标位恢复遗留的三万黄标。
- 灰桌真空位匹配通过。有实始牌面边缘证据时，空位匹配保留待核对。在另一局灰桌中牌河输出维持原样，真白板未被判为空位。
- 赤五标签独立保存。朝向不同、遮挡、相似样本标签冲突、牌数超限时保留原结果或黄标。
- 这批独立整桌没有命中高置信度的纠错，独立牌局复现近似万子错读后的收益还未验证。被遮挡的牌和无法确定布局的牌河位置仍需用户确认。首期学习范围是手牌、牌河和有明确朝向的自家副露。
